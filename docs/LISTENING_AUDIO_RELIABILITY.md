# 听力播放器与核验状态修复

2026-09-23

- 本地服务提供 Content-Length、音频 MIME、HEAD 和单段 Range（206 / 416），使用流读取文件。
- 播放器在时长有效后恢复位置；监听 durationchange，避免加载未完成时覆盖保存进度。
- 销毁播放器时取消事件，避免旧 Part 的媒体事件影响新 Part；倍速、位置、A–B 循环按 Part 保存。
- 修复音频末尾循环时 ended 状态在 seek 后改变、导致无法继续播放的问题。
- 旧版 C18 T1 手工题库覆盖过时的 verified 标记为 false。题目、答案待复核，音频内容待听辨；提交、报告和重做不自动判分。保留参考答案及原卷页码链接。
- 新导入 JSON 的状态由现有导入目录独立管理；新数据验证不能自动认证旧题库副本。
