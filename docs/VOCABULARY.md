# 本地记单词

## 阅读生词与听力精听

阅读页工具菜单中的“收藏选中生词”支持单词或最多 8 词的短语，可手填释义或留空，保存附近原文、文章标题、PDF 页码及阅读链接。词书页“我的阅读生词”接入翻卡、拼写、听写、收藏和复习。相同英文使用相同 ID，共享学习进度；再次收藏更新原文片段，不重复新增。词条本身保存在 `ielts-personal-words-v1`，当前进度 JSON 备份不包含该词条库，尚不能用进度文件单独迁移阅读生词内容。

听力学习模式及错题回听提供 0.75 / 0.85 / 1 / 1.15 / 1.25 倍速与 A–B 循环，B 须在 A 之后至少 0.5 秒。学习会话按 Part 保存速度和有效循环区间，切换 Part 隔离；错题临时回听不持久化。模考模式不显示精听控件。

验证：阅读选区收藏到生词列表的浏览器链路通过；A–B 回跳、速度与持久化使用模拟媒体元数据验证，未对所有真实音频做听感测试。

入口：`/words.html`，网站顶部导航“记单词”。

## 词库

`WORD/` 顺序版 XLS 的两张表通过 xlrd 本地读取，生成 `resources/words/manifest.json` 及两份 JSON：常用词汇 7,956 词、完整词汇 9,389 词。每个词保留来源行号，词书保留来源文件 SHA-256 与工作表名称。重复英文合并释义，词 ID 根据英文生成，以便两本书共享学习记录。

未重复导入乱序版。源文件未修改。释义使用原表内容，未补写音标、例句或 AI 翻译。

分类 PDF 使用 `python lib/import_word_pdfs.py` 本地文字层规则提取：听力 1,652 条，阅读 4,381 条，保留主题、原始文字及来源页码。支持主题筛选、按主题学习和原书定位。词条未经逐项核验，页面标记待校对；148 个听力片段与 263 个阅读片段未可靠解析，保存在 `resources/words/pdf-import-report.json`，不能将已提取数量视为整本完整覆盖。

记忆法共 512 页，仅 6 页存在文字层。目前提供原 PDF 阅读与手动页码书签，保留联想、例句和插图；尚未 OCR 为单词卡。两种导入命令均保留其他来源的词书条目。

重建命令：`python lib/import_words.py`。依赖 xlrd 安装于项目 `.cache/word-import-deps`；不影响 Cambridge 导入器。

## 学习

- 每组 10 / 20 / 30 / 50 个新词，支持随机顺序。
- 翻卡查看释义，按认识程度安排复习；拼写自测不计大小写。
- 不认识：10 分钟；模糊：1 天；连续认识逐步延长至 1、3、7、14、30、60 天。
- 刷新后从词书页继续上次队列；收藏、英文/中文搜索、分页列表。
- 记录存在 `ielts-vocabulary-v1`，支持导出与导入 JSON 备份。导入先验证记录与队列，显示摘要并确认替换，原始记录保存到 `ielts-vocabulary-v1-before-import`，可通过“导入前备份”下载。每次成功执行备份写入会更新这个回滚槽。不会自动同步设备，也不影响模考数据。
- 导入备份时必须有相应的词书与队列词条；当前不支持阅读选词收藏。备份校验及写入失败保护由 `tests/word-backup.test.js` 覆盖。
- 单词卡提供正常/慢速发音，使用浏览器可用英文语音，优先英音。没有英文 voice 时显示错误；音质与可用性取决于设备，不保证离线。
- 听写新词隐藏英文及释义，提交后揭示。拼写错误和“不认识”记入 `needsPractice`，词书页有错词入口，组末可再练本组错词。正确拼写后移除待强化标记；单击“认识”不会自动清除错词。
- 浏览器测试验证语音 API 调用与慢速参数（使用模拟语音接口），未验证真人设备的实际声音。听写答案隐藏、错词保存、组末强化和正确后移除已验证。
- 分组数量不是严格的每日上限；暂未实现每日打卡。

## 验证

16 项 Node 测试通过。`node tests/words-browser.mjs` 覆盖词书加载、翻卡、评级保存、拼写、刷新续学、搜索、收藏及手机布局。测试使用独立浏览器 profile，不修改日常浏览器学习记录。
