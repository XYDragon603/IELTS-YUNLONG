# 听力作答与交卷改进

从题库 Test 详情的“听力计时练习 · 开始 / 继续”进入，沿用原有 `ielts-study-v1` 记录。导入 JSON 听力仍标为“导入题预览”，两者尚未合并数据源。原卷、精讲与音频资源折叠到详情页下方。

新增暖白卡片作答区、桌面粘性音频栏与题号导航。交卷检查按 Part 显示作答计分点、待填计分点、标记题组数；多选题部分作答会计为未完成，支持跳回第一道缺失题。计时仍是原有 30 分钟练习计时，允许暂停退出，不宣称严格还原正式机考。

复盘提供全部、需复盘、待核对筛选。`verified !== true` 的试卷不输出确定逐题分数。提交写入失败时保留可继续的会话，不导航到成功页。未修改题库数据或导入流程，也未独立核验现有 verified 标记。

验证：24 项 Node 测试通过；`node tests/listening-browser.mjs` 覆盖开始练习、四个 Part 交卷检查、漏题跳转、交卷、复盘筛选和手机复盘宽度。尚未完成四科连续全套模考和正式计时规则。
