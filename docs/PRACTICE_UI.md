# 三科练习界面

## 交卷前检查

阅读按 Passage 显示已答、待填和标记数，返回检查优先聚焦漏题；写作显示每篇字数和题目要求，区分空白与字数不足；口语逐 Part 检查 IndexedDB 已保存录音，读取失败标记状态未知，不误报未录音。所有提醒均允许用户确认后交卷，不代表自动评分或内容质量核验。

检查界面保留取消、返回指定分段和确认提交。浏览器回归覆盖写作返回修改再提交，以及原有三科草稿、历史和录音流程；单元测试覆盖阅读重复题号去重、漏题定位和写作字数检查。

## 阅读辅助工具

阅读支持 16 / 18 / 20 / 22px 字号、按文本段定位、选中文字高亮及清除本篇高亮。手机宽度下通过“文章 / 题目”切换面板；电脑保留双栏。字号和面板偏好保存在 `ielts-reading-preferences-v1`。

高亮保存在当前练习的 `readingMarks`，随提交记录归档，历史记录只读。高亮记录包含原文本与选区位置，导入文本变化时不套用旧高亮。仅支持同一个文本段内的选区，不进行答案定位推断。

本次前端验证：14 项 Node 测试通过；无头 Chrome 覆盖高亮刷新恢复、清除、字号保存、手机面板切换及段落定位，同时回归写作草稿、提交历史与口语录音流程。未运行或修改资料导入流程，前端通过不代表 OCR 内容已验证。

## 练习历史与重做

三科页面底部显示当前试卷、当前科目的提交历史。提交时保存答案、题库快照和阅读参考结果；查看历史不会覆盖当前草稿。点击“重新练习（保留旧记录）”会加载最新题库，创建新的答案、计时与录音空间。

历史写入独立的 `ielts-practice-v1-c{book}-t{test}-{skill}-history` localStorage 键；若空间不足或历史损坏，则提示错误，不覆盖旧历史。查看历史无需重新请求题库 JSON。旧版已提交记录会迁移，页面明确说明首次提交时的题库版本无法还原。

口语录音现在按练习ID及Part分别保存；新一轮录音不会替换旧练习录音。单轮中再次录制同一个Part仍保留最新一段，可先下载备份。

启动：`npm.cmd start`，从题库 Cambridge 18 → Test 1 进入阅读、写作或口语。

- `/practice.html?skill=reading`：文章/题目分栏、题组原图、题号导航、标记、答案保存和提交复盘。
- `/practice.html?skill=writing`：Task 1/2、图表、字数统计、独立草稿、提交后只读和导出。
- `/practice.html?skill=speaking`：Part 1–3、话题卡、准备/作答计时、笔记、录音回听和下载。

可追加 `book=18&test=1` 指定试卷。其他试卷只有对应 JSON 存在时才能打开。数据格式见 DATA_AGENT_HANDOFF.md。

阅读与写作计时默认60分钟，手动开始/暂停；到时提醒并保存，不强制提交。口语支持1分钟准备和2分钟作答计时。离开时暂停练习计时。

草稿使用 `ielts-practice-v1-c{book}-t{test}-{skill}` localStorage 键；录音使用独立 IndexedDB 数据库 `ielts-practice-recordings-v1`，每个 Part 保留最近一次录音。重新录制前可下载旧录音备份。导出 JSON 包含文字与答案，录音需单独下载。录音只在用户点击按钮并授权麦克风后开始。

当前资料待复核。界面如实展示数据缺失，未确认阅读答案不计为错误；写作和口语无自动评分。资料 agent 修复 JSON 后，刷新页面即可载入，仍应核对新版本题号与旧草稿是否一致。

验证命令：`npm.cmd test`、`npm.cmd run check`；先启动本地服务器后运行 `npm.cmd run test:practice`。浏览器测试使用独立 Chrome profile 和模拟麦克风，不使用真实麦克风。
