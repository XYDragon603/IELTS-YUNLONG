# 阅读与听力错题复盘

入口：`/review.html`。剑 14–15 等已导入试卷交卷后，阅读练习页和听力导入预览的每题结果都有“加入复盘清单”。用户主动选择要复做的题；未核验题库不会被自动判为错误。首页导航的“错题复习”进入此页，旧版听力错题也在页面下方提供原有复做入口。

复盘项只保存题目快照、作答记录、来源页、已提取的短证据和同义替换，不复制整份 PDF 或试卷。浏览器本地存储键为 `ielts-review-v1`；可以从页面导出 JSON。题库中明显过长或带 OCR 噪声的阅读题干改为“待核对”提示，原始提取文本保留在折叠区域，原卷链接始终可用。

复做时先填写答案，再展开参考答案、证据和同义表达，并可将表达收藏到词书。只有来源 `verified: true` 且存在可用答案时才自动判断是否匹配；未核验题记录答案和复做次数，掌握状态由用户自评。复做失败或待核验题安排次日再看，已核验且答对或用户标记已掌握的题安排 7 天后复看。这是简单本地提醒规则，不是考试评分。

验证：`npm test`、`npm run check`、`npm run test:import-preview`、`node tests/synonym-reading-browser.mjs`。
