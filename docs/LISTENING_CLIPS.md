# 精听片段收藏

在听力学习模式或错题重做中设置 A、B，展开「收藏当前精听片段」，填写可选题号和笔记，然后保存。

从播放器「我的精听收藏」或错题复习页进入 `/listening-clips.html`。选择片段后恢复对应 Test / Part 的音频、倍速、循环范围；点击播放开始回听。此页也可把相关词汇加入现有个人生词本（当前名称仍为「我的阅读生词」），保留片段来源链接。

- 使用 `ielts-listening-clips-v1` localStorage，独立于答题记录与单词进度。同一 Test、Part 和精确 A–B 区间重复保存会更新笔记及题号。
- 题号必须属于对应 Part；拒绝倒置或不足 0.5 秒的区间。损坏记录不自动覆盖；保存失败会显示错误。
- 模考模式不提供片段收藏，原始音频和导入资料保持不动。
- 片段由用户手动标记，未经过内容听辨，不能视为官方逐题时间戳。没有自动生成或宣称已完成声音内容核验。
- 收藏只在当前浏览器保存；现有单词进度备份不包含精听片段。
