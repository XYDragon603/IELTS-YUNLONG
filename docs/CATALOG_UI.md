# 动态题库与入口

运行 `npm.cmd start`，打开 `http://127.0.0.1:4173/#library`。

`GET /api/catalog` 在每次请求时读取 `resources/cambridge/c4` 至 `c20` 的 Test 1–4 四科 JSON，不改写题库数据。无需运行扫描脚本，新增或修复 JSON 后刷新页面或点击“刷新题库”即可发现。

界面可按册次、Test、科目和状态筛选。试卷详情显示四科状态以及继续练习、提交记录和三科历史入口。首页和总历史页展示本机阅读、写作、口语草稿及提交历史；听力预览草稿显示在继续练习中，原听力记录入口保留。

状态含义：
- 可练习：导入数据声明 verified，未列出待复核项，且基本结构和必要图片/音频检查通过。
- 待复核：导入内容尚未确认或基本内容不完整；有可展示内容时允许练习。
- 资料缺失：声明 missing-resource，或引用的必要图片/听力音频/听力稿缺失，禁用入口。
- 尚未导入：对应科目 JSON 不存在。

索引检查不代替内容审校。JSON 正在写入或损坏时显示待复核并禁用入口，不影响其他试卷。接口仅返回题库摘要，不向页面发送整本正文。

现有统一题库覆盖4–20册，每册Test1–4。历史和草稿仍在本机浏览器，同一主机名和端口下才能访问原记录。
