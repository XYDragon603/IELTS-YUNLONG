# 四科连续练习

入口 `/mock.html`，顶部导航“整套练习”。当前只开放 Cambridge 18 Test 1，开始前检查四科导入资源可用性。

整套索引保存于 `ielts-mock-runs-v1`。听力使用现有 `ielts-study-v1` 会话并附加 `mockRun`；阅读、写作、口语使用带 run ID 的独立草稿、历史与录音命名空间，不覆盖单科草稿。每科交卷后回整套进度页，下一科解锁。已完成的科目可进入复盘。

此版本是可暂停、可分次完成的连续练习，不是严格正式模考；不自动播放下一段、不生成总 Band，不为写作口语评分。听力使用原有结构化数据，其他科使用导入 JSON，尚未完成统一内容核验。词书进度备份不包含整套记录。

测试 `tests/mock-run.test.js` 检查顺序限制、隔离键和解锁；`tests/mock-browser.mjs` 检查新建、四科空白交卷（允许确认后提交）、查看复盘和最终完成状态。实际音频听感与口语内容质量不在此测试范围内。
