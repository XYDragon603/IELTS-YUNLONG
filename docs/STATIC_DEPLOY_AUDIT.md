## 必须处理

- features/mock.js: /api/catalog
- ui/import-catalog.js: /api/catalog
- 将 /api/catalog 在构建时生成为静态 JSON，并调整以上两处请求；新增题库后重新构建。
- 超过 25 MiB 的资源不能直接上传 Cloudflare Pages，可改放对象存储；替换资源地址后检查音频拖动、跨域请求及 PDF 链接。
- WORD/雅思记忆法.pdf 被词库阅读器引用，但当前 Node 公共路径白名单未放行；保留该入口时需要部署此文件或修改入口。其余 WORD 源文件无需发布。
- 没有现成的 service worker 离线缓存；静态托管不等于完整离线可用。

## 无需上传

server.js、package.json（构建环境可用，但不属于浏览器文件）、lib/catalog-server.js、lib/http-range.js、lib/public-path.js、IELTS-Studio/、scripts/、tests/、docs/、artifacts/、.git/、.github/、.cache/、.chrome-*/、.pytest_cache/、__pycache__/、cleanup-c-drive-safe.ps1、WORD 内未引用的源文件。

resources 内的 OCR/validation/import 审计文件、page-maps、未被前端引用的 synonyms 源索引无需上传；以 JSON 清单为准，避免整目录发布。
